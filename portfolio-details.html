Mi Primera Página Web

Este proyecto es una página web sencilla creada mientras estudio SMX. Me ha servido para practicar HTML, CSS y estructura básica de diseño. Aunque es un proyecto simple, representa mis primeros pasos en el desarrollo web.

HTML CSS Proyecto Escolar

Mi Proceso de Aprendizaje

Este proyecto lo hice para practicar cómo estructurar una página web desde cero. Empecé aprendiendo lo básico: etiquetas, estilos y cómo organizar el contenido.

También trabajé en mejorar la presentación visual, usando colores, imágenes y una distribución clara para que la web fuera fácil de entender.

Cada pequeño avance me ayudó a entender mejor cómo funciona el desarrollo web y me motivó a seguir aprendiendo más.
