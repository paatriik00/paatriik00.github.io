    Desenvolupament Web Bàsic

    Creo pàgines web senzilles i funcionals mentre continuo aprenent a SMX. M’agrada transformar idees en webs clares, útils i fàcils d’utilitzar.

    Què inclou?

    Aquest servei està pensat per a persones que necessiten una web bàsica per començar. Em centro en crear dissenys simples, ordenats i adaptats a les teves necessitats.

    Disseny Personalitzat

    Un estil visual senzill i adaptat al que busques.

    Codi Net

    HTML i CSS organitzats perquè sigui fàcil de mantenir.

    Responsive

    La web s’adapta a mòbils, tauletes i ordinadors.

    Optimització Bàsica

    Millora de càrrega i visibilitat per a un millor rendiment.

    El meu procés

    01

    Reunió Inicial

    Parlem sobre el que necessites i el tipus de web que vols.

    02

    Disseny

    Creo un disseny senzill i clar basat en les teves idees.

    03

    Desenvolupament

    Construeixo la web amb HTML i CSS, assegurant que funcioni bé.

    04

    Entrega

    Revisem la web i la deixo llesta per utilitzar.

    Detalls del Projecte

    • Temps estimat: 1-2 setmanes
    • Revisions: 2 incloses
    • Tecnologies: HTML, CSS, JavaScript bàsic
    • Suport: 15 dies després de l’entrega
